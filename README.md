𝕏 Twitter Clone
A full-featured Twitter clone with user authentication and real-time posting.
🏷️ Built With
React • Vite • Redux Toolkit • Firebase • Bootstrap • Axios • JavaScript
✨ Features
🔐 Authentication — Secure Firebase login & signup
💬 Posts — Create, delete, and view tweets
👥 Profiles — User profiles with post history
⚡ Real-time Sync — Instant updates with Firebase
🎨 Responsive Design — Mobile-friendly UI
🔄 State Management — Redux for global state
🚀 Quick Start
Bash
🧠 Tech Stack
Frontend: React 18 + Vite
Authentication: Firebase Auth
Database: Firebase Firestore
State: Redux Toolkit
Styling: Bootstrap 5
HTTP: Axios
